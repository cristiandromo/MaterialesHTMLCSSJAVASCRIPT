Notas de Funciones en Python

Resumen útil para repasar antes del examen.

Concepto principal

¿Qué es una función?

Una función es un bloque de código reutilizable que realiza una tarea específica. Se define una vez y se puede llamar muchas veces.

def nombre_funcion(parametros):
    # bloque de código
    return resultado
  • def: palabra clave para definir la función.
  • nombre_funcion: nombre que usamos para invocarla.
  • parámetros: datos que recibe la función.
  • return: devuelve un valor al programa principal.
Ejemplo básico

Función sin parámetros

def pintar_cuadrado():
    print("""
    * * * *
    *     *
    * * * *
    """)

pintar_cuadrado()

Se usa cuando la función no necesita recibir información. Solo ejecuta una acción.

Funciones con parámetros

Pasar información

def suma(num1, num2):
    r = num1 + num2
    print(r)

suma(5, 3)
  • Los parámetros sirven para recibir valores.
  • La función puede trabajar con esos valores y devolver resultados.
Operaciones

Funciones para cálculos

def suma(num1, num2):
    return num1 + num2

def resta(num1, num2):
    return num1 - num2

Cuando se usa return, la función entrega un valor que se puede guardar en una variable o imprimir.

Importante

Parámetros por posición y por nombre

def resta(num1, num2):
    return num1 - num2

print(resta(5, 4))
print(resta(num1=5, num2=4))
  • Por posición: el orden importa.
  • Por nombre: se indica el nombre del argumento.
  • Esto es útil cuando hay muchos parámetros.
Parámetros por defecto

Valores predeterminados

def suma(a, b, c=8):
    return a + b + c

print(suma(5, 5, 3))
print(suma(4, 3))

Si no se pasa un valor para c, Python usa el valor por defecto.

Los argumentos por defecto se escriben al final.

*args

Argumentos variables

def suma(*args):
    total = 0
    for i in args:
        total += i
    return total

print(suma(5, 8))
print(suma(5, 8, 1, 2, 3))
  • *args recibe varios valores en una tupla.
  • Se usa cuando no sabemos cuántos datos entrarán.
**kwargs

Argumentos con nombre

def datos_personales(**kwargs):
    for clave, valor in kwargs.items():
        print(clave, valor)

datos_personales(nombre='ana', edad=20, correo='a@a.com')
  • **kwargs recibe varios argumentos en formato clave: valor.
  • Se guarda como diccionario.
Combinación

Parámetros mixtos

def guardar(nombre, apellido, *args, activo=False, **kwargs):
    print(nombre)
    print(apellido)
    print(activo)
    print(kwargs)

guardar('ana', 'perea', 1, 2, 3, activo=True, al='yuliano')

El orden recomendado es:

  • parámetros normales
  • *args
  • parámetros por defecto
  • **kwargs
Funciones avanzadas

¿Qué son las funciones avanzadas?

Las funciones avanzadas son funciones que trabajan con datos más complejos: listas, diccionarios, varios argumentos, condiciones internas y estructuras de retorno más elaboradas. No son otra cosa que funciones más flexibles y reutilizables.

  • Reciben muchos datos sin saber de antemano cuántos son.
  • Permiten filtrar, transformar o preparar información.
  • Pueden devolver un diccionario, una lista o una estructura de datos.
  • Son útiles para crear reportes, menús, validaciones y filtros.
Ejemplo 1

Función con *args y parámetros opcionales

def generar_reporte(*producto, descuento=0, moneda="COP", incluir_total=True):
    resultados = {}
    cont = 0

    for pro in producto[0]:
        if descuento == 0 or descuento >= 50:
            desc = pro["precio"]
        else:
            desc = pro["precio"] - (pro["precio"] * (descuento / 100))

        p_retorno = {
            "nombre": pro["nombre"],
            "precio": desc,
            "cantidad": pro["cantidad"],
            "moneda": moneda,
        }

        if incluir_total:
            p_retorno["subtotal"] = desc * pro["cantidad"]

        cont += 1
        resultados[cont] = p_retorno

    return resultados

En este ejemplo, la función recibe varios productos a la vez, aplica un descuento opcional y genera un reporte con información organizada.

  • *producto: acepta varios elementos como una tupla.
  • descuento: parámetro opcional con valor por defecto.
  • incluir_total: decide si agrega subtotal o no.
Ejemplo 2

Filtrado con **kwargs

def filtrar_estudiantes(estudiantes, **kwargs):
    lista_filtrada = []

    for est in estudiantes:
        cumple = True

        for criterio, valor in kwargs.items():
            if criterio == "ciudad" and est["ciudad"] != valor:
                cumple = False
            if criterio == "edad_minima" and est["edad"] < valor:
                cumple = False
            if criterio == "nota_minima":
                if not any(nota >= valor for nota in est["notas"]):
                    cumple = False

        if cumple:
            lista_filtrada.append(est)

    return lista_filtrada

Este tipo de función permite aplicar varios filtros al mismo tiempo, sin necesidad de escribir un código separado para cada criterio.

  • **kwargs captura criterios como ciudad, nota o edad.
  • Se usa mucho en búsquedas y validaciones.
Ejemplo 3

Menú dinámico con kwargs

def construir_menu(prefijo="-", mayusculas=False, **kwargs):
    salida = []

    for categoria, items in kwargs.items():
        if mayusculas:
            categoria = categoria.upper()
        salida.append(categoria)

        if len(items) == 0:
            salida.append("[VACÍO]")
        else:
            for item in items:
                salida.append(f"{prefijo} {item}")

    return salida

La función construye un menú sin saber cuántas categorías o elementos tendrá. Esto es típico de funciones avanzadas: generan resultados dinámicos.

Concepto clave

¿Por qué son importantes?

  • Permiten resolver problemas con datos variables.
  • Hacen que el código sea más limpio y reutilizable.
  • Ayudan a crear soluciones más generales para distintos casos.
  • Son la base de programas más complejos y funciones de librerías.

En resumen, una función avanzada no es “más difícil”, sino que maneja más variedad de entradas y produce información más útil y organizada.

Ejercicio del edificio

Explicación del ejercicio de empleados y ubicaciones

Este ejercicio trata de un sistema de registro de empleados en un edificio, donde cada persona tiene nombre, cargo, ID y una ubicación actual (piso y oficina). Luego se pueden mover entre oficinas y se deja un historial de todos los movimientos.

La idea central es separar la información en dos diccionarios:

empleados = {
    "nombre": ["Andrea", "Pedro"],
    "cargo": ["Gerente", "Contador"],
    "id": [789, 123]
}

ubicacion = {
    "empleado": [789],
    "piso": [5],
    "oficina": [1]
}

Esto significa que cada posición del arreglo corresponde a la misma persona en los tres arreglos. Por ejemplo, el empleado ubicado en la posición 0 es Andrea con ID 789 y está en el piso 5 oficina 1.

Cómo pensar la lógica

  • Primero se registran los empleados con una función.
  • Luego se valida que el ID sea único.
  • Cuando un empleado se mueve, el sistema guarda un nuevo registro en ubicacion.
  • Para saber el último lugar, se busca el último movimiento del empleado.
  • Para saber todo el historial, se recorren todos los registros y se filtran por ese ID.
def registrar_empleado(nombre, cargo, id_empleado):
    empleados["nombre"].append(nombre)
    empleados["cargo"].append(cargo)
    empleados["id"].append(id_empleado)

La función registrar empleado no hace operaciones complejas: solo agrega la información a las listas.

def mover_empleado(id_empleado, piso, oficina):
    if id_empleado in empleados["id"]:
        ubicacion["empleado"].append(id_empleado)
        ubicacion["piso"].append(piso)
        ubicacion["oficina"].append(oficina)

El truco aquí es que no se reemplaza el lugar, sino que se agrega un nuevo movimiento. Así queda el historial completo.

Cómo sacar el último lugar

def ultimo_lugar(id_empleado):
    for i in range(len(ubicacion["empleado"]) - 1, -1, -1):
        if ubicacion["empleado"][i] == id_empleado:
            return ubicacion["piso"][i], ubicacion["oficina"][i]
    return "No tiene movimientos"

Este patrón es importante: recorrer la lista al revés para obtener el último registro.

Cómo sacar todo el historial

def historial_empleado(id_empleado):
    historial = []
    for i in range(len(ubicacion["empleado"])):
        if ubicacion["empleado"][i] == id_empleado:
            historial.append((ubicacion["piso"][i], ubicacion["oficina"][i]))
    return historial

Si el empleado nunca se movió, la lista resulta vacía, y entonces puedes mostrar: “No tiene movimientos”.

Menú del sistema

while True:
    print("1. Registrar empleado")
    print("2. Mover empleado")
    print("3. Ver último lugar")
    print("4. Ver historial")
    print("5. Salir")
    op = int(input("Opción: "))

La idea del menú es muy simple: cada opción llama a una función distinta y siempre repite hasta que el usuario salga.

Trucos para estudiar mejor

  • Identifica primero las dos estructuras principales: empleados y ubicacion.
  • Piensa en “índices”: cada elemento en una lista representa la misma persona en otra lista.
  • Cuando necesites el último movimiento, escanea desde el final hacia el inicio.
  • Cuando necesites historial, recorre todo el diccionario y filtra por ID.
  • Usa funciones pequeñas: registrar, mover, ultimo_lugar, historial.
  • Valida primero si el empleado existe antes de moverlo.
  • Haz ejercicios con papel: dibuja las listas y sigue qué índice corresponde a cada persona.

Regla de oro: no intentes resolver todo en una sola función. Divide el problema en registrar, mover y reportar. Eso es lo que hace que el ejercicio sea entendible y se vea “claro” para la sustentación.

Ejercicio 1

Contar y guardar números primos del 0 al N

Este ejercicio pide: “calcular cuántos primos hay desde el 0 hasta N” y guardar esos primos en una lista. 

def es_primo(num):
    if num < 2:
        return False
    for i in range(2, int(num**0.5) + 1):
        if num % i == 0:
            return False
    return True

def primos_hasta_n(n):
    primos = []
    for i in range(0, n + 1):
        if es_primo(i):
            primos.append(i)
    return primos
  • La clave es crear una función es_primo().
  • Luego otra función que recorra desde 0 hasta N.
  • Se guarda cada primo en una lista.
  • Al final se imprime la lista y la cantidad de primos.

Idea clave: un número primo solo es divisible entre 1 y sí mismo; por eso se prueba hasta la raíz cuadrada.

Ejercicio 2

Revisar si una lista de números es primo o no

Este ejercicio pide revisar una lista ingresada por el usuario y separar los números en dos grupos:

  • primos
  • no_primos
def es_primo(num):
    if num < 2:
        return False
    for i in range(2, int(num**0.5) + 1):
        if num % i == 0:
            return False
    return True

def clasificar_numeros(lista):
    primos = []
    no_primos = []

    for num in lista:
        if es_primo(num):
            primos.append(num)
        else:
            no_primos.append(num)

    return {"primos": primos, "no_primos": no_primos}

Se usa un diccionario para guardar dos listas. Eso responde al enunciado: clave "primos" y clave "no_primos".

Es una versión más organizada del ejercicio 1 porque además de verificar, clasifica la información.

Ejercicio 3

Simulación de Tienda Virtual

Este es el ejercicio más importante del PDF. La tienda tiene 3 productos:

  • Camisa: precio 5000, existencia 10
  • Pantalón: precio 7000, existencia 5
  • Traje: precio 10000, existencia 82

El cliente debe registrar nombre, apellido, edad y dinero. Sólo pueden comprar si son mayores de edad.

Funciones que se piden

  • comprarProducto(): disminuye inventario y resta dinero.
  • devolverProductoDefectuoso(): aumenta defectuosos y devuelve dinero al cliente.
  • mostrarEstadoTienda(): imprime productos, existencias y defectuosos.
  • mostrarEstadoCliente(): muestra dinero disponible y última acción.
productos = [
    ["camisa", 5000, 10, 0],
    ["pantalon", 7000, 5, 0],
    ["traje", 10000, 82, 0]
]

def comprar_producto(cual, cantidad, dinero):
    costo = productos[cual][1] * cantidad
    if cantidad <= productos[cual][2] and dinero >= costo:
        productos[cual][2] -= cantidad
        dinero -= costo
        return dinero, "Comprar"
    return dinero, "No se pudo comprar"

La lógica principal es:

  • mostrar inventario
  • preguntar qué desea comprar
  • validar si hay stock
  • restar costo al dinero
  • guardar la última acción

Regla clave: sólo puede devolver un producto si la acción anterior fue comprar. Eso se controla con una variable como ultima_accion.

Ejercicio 4

Simulación de banco

Este ejercicio crea tres clientes y les permite hacer operaciones bancarias mediante funciones.

  • depositarDinero()
  • retirarDinero()
  • transferirDinero()
  • comprar()
  • mostrarSaldo()
clientes = {
    "cliente1": {"nombre": "Ana", "cuenta": 101, "saldo": 0},
    "cliente2": {"nombre": "Luis", "cuenta": 102, "saldo": 0},
    "cliente3": {"nombre": "Sara", "cuenta": 103, "saldo": 0}
}

def depositar_dinero(cliente, valor):
    clientes[cliente]["saldo"] += valor


def retirar_dinero(cliente, valor):
    if clientes[cliente]["saldo"] >= valor:
        clientes[cliente]["saldo"] -= valor

Las validaciones más importantes son:

  • No se puede comprar si el producto cuesta más que el saldo.
  • No puede retirar si el saldo está en cero.
  • No puede retirar más de lo que tiene.
  • La cuenta no puede quedar en saldo negativo.
  • Los productos deben costar más de 5000.

La lógica del menú es cíclica: se le pregunta al usuario con cuál cliente va a trabajar y luego qué operación desea realizar. Cuando sale, se muestran los clientes y sus saldos.

Funciones para una tienda

def comprar_producto(cual, cantidad, dinero, ultima_accion):

Resumen

Puntos clave para el examen

  • Una función sirve para reutilizar código.
  • Se define con def.
  • Pueden recibir parámetros y devolver resultados con return.
  • Los argumentos por posición y por nombre son importantes.
  • Los valores por defecto facilitan el uso de funciones.
  • *args permite recibir varios valores.
  • **kwargs recibe nombre y valor.
  • Las funciones ayudan a organizar un programa.
